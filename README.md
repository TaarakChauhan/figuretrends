# Figure Trends

Weekly collectible figure lists for [figuretrends.com](https://figuretrends.com).

## Morning setup checklist

1. Open https://github.com/TaarakChauhan/figuretrends
2. Confirm Vercel project `figuretrends` is deployed
3. In Vercel → Project → Settings → Domains, add `figuretrends.com` and `www.figuretrends.com`
4. In Namecheap, point DNS to the records Vercel shows (usually A / CNAME)
5. Create a free Beehiiv or Buttondown account and replace the homepage email form later
6. Apply to Amazon Associates Canada and one figure retailer affiliate program
7. Do not reopen Shopify. Do not buy ads this week.
